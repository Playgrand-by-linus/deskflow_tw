# Deskflow Traditional Chinese Localization

Traditional Chinese (zh_TW) localization and release distribution context for Deskflow (`deskflow_tw`).

## Language

**Server (伺服器 / 主控端)**:
The primary computer providing physical mouse and keyboard input to control other machines.
_Avoid_: 服務端, 控制端, 主機

**Client (用戶端 / 被控端)**:
A computer receiving simulated mouse and keyboard input forwarded over the network.
_Avoid_: 客戶端, 接收端, 從機

**Screen (螢幕)**:
A computer display represented as a node in the grid-based spatial arrangement.
_Avoid_: 屏幕, 顯示器

**Clipboard (剪貼簿)**:
The shared text and data copy-paste buffer synchronized across connected machines.
_Avoid_: 剪貼板, 剪切板

**Daemon (背景服務)**:
The background service process running with elevated system permissions for UAC and login screen operation.
_Avoid_: 守護進程, 後台進程, 常駐程式

**Hotkey (快捷鍵 / 熱鍵)**:
Configurable key combinations used to trigger actions like screen switching or cursor locking.
_Avoid_: 快顯鍵, 組合鍵 (除非指單純 modifier)

**Fingerprint (憑證指紋)**:
Cryptographic hash representation used to verify TLS identity between computers.
_Avoid_: 密鑰標記, 認證指紋
