# Agent Guidelines - deskflow_tw

This file defines the project-scoped guidelines and rules for AI agents working in this repository (`deskflow_tw`).

## Agent skills

### Issue tracker

Tracked in GitHub Issues using `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical five-role triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
