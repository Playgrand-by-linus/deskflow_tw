# Version Tagging and Translation Completeness Standard

We decided to target 100% translation coverage (zero unfinished entries) and adopt an upstream-linked version tagging scheme (`v<upstream-version>-tw<revision>`).

## Context

Previous translations had incomplete entries marked as unfinished. To deliver a polished first-class experience for Traditional Chinese users, all 314 strings are fully translated and proofread using standard Taiwanese localization conventions (English modifier keys and hotkey accelerators preserved). Version tags directly reflect the upstream codebase version to ensure clarity regarding feature and security parity.
